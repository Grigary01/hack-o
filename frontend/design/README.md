# Дизайн фронтенда

Положите сюда макеты, скриншоты, исходники дизайна и используемые визуальные материалы.
Если дизайн находится в Figma или другом сервисе, добавьте ссылку и краткие пояснения в этот файл.

## Untitled.pdf — макет MVP (Figma, 8 страниц, 1440 × 1040)

| Стр. | Экран | Реализация в `web/` |
|---|---|---|
| 1 | Выдача: чипы запроса, фильтры, группы «Условия подтверждены / Не все условия подтверждены», схематическая карта | `/search` — `ResultsPage` |
| 2 | Главная Островка (референс стиля: зелёный hero, поля поиска, поле «Что важно для проживания?») | `/` — `HomePage` |
| 3 | Выдача Островка (референс: фильтры, карточки отелей, карта с ценами) | стиль `ResultsPage` |
| 4 | Карточка отеля/номера, «На чём основан подбор» | `/hotels/:id` — `HotelPage` |
| 5 | Кабинет отельера: вопрос «Есть ли в номерах шторы blackout?» | `/hotelier/:hotel/questions` |
| 6 | Ответ отельера свободным текстом | `/hotelier/:hotel/questions/:id` |
| 7 | Проверка разбора ответа перед публикацией | `/hotelier/:hotel/answers/:id/review` |
| 8 | Результат: характеристики обновлены, «Как увидит гость» | `/hotelier/:hotel/answers/:id/published` |

Цвета, отступы и типографика сняты с макета в `web/src/styles/tokens.css`.
Батуми, цены, категории номеров и blackout в макете — демонстрационные: текущий API их не поддерживает
(см. `web/README.md`, раздел «Что ждёт контракта бэкенда»).
